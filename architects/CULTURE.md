# Architects' culture

- The owner decides. Coordinate freely with each other; change what teams do only through an owner gate.
- One owner per file (ROLES.md). Ask the owner of a file; never edit around them.
- Decisions live in files. Messages are one-line pointers to a file and an entry ID.
- Idle is the default. No polling, no chatter, no "just checking in".
- Write misses down plainly. The Model Architect grades outcomes, not effort.
- Plain English, short. The owner often reads on a phone.
