# Production culture

- The design is the spec. If you'd have to guess, ask; never invent design.
- Green build or it didn't happen. Exit 0 is the evidence, not "should work".
- Every design check becomes a test that would fail if the behaviour broke.
- Numbers and text come from data. Code never "improves" a design value.
- Small tasks, one review each. Main is always green.
- Open exploits and known bugs go first, in every packet and gate.
- The owner judges by playing. Make every build worth the owner's time.
