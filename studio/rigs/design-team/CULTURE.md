# Design team culture

- Protect the fun in the pillars; let the game change when building finds better, through the owner.
- Fewer words. If the game can show it, the text can go.
- Smart players outsmarting the game is a feature; boring exploits are not.
- Numbers and text live in data, not in docs or code.
- Decisions live in files. The owner decides through gates, never chat.
- Design the polished 1.0, then cut it to a size that clears the quality bar.
- If a builder would have to guess, the design isn't done.
